# UI звонков Discord (референс)

Как Discord показывает участников и момент звонка **до ответа**. Это визуальный ориентир для Pulse; транспорт и сигналинг — в [voice.md](./voice.md).

Два разных продукта в одном клиенте Discord:

| | DM / Group DM call | Voice channel (сервер) |
|---|---|---|
| Вход | Кнопка «Call» → ринг, ждут accept | Join без ринга |
| Пока никто не ответил | Полноценная сцена «Calling…» у звонящего | Не применимо |
| Участники на сцене | Тайлы (сетка / strip при шаре) | Тайлы на сцене **или** только список под каналом + rail |
| Церемония | Есть (ring → accept / decline / timeout) | Нет (presence = приглашение) |

Pulse копирует **оба**: `CallOverlay` ≈ DM call, `VoiceOverlay` + dock ≈ voice channel.

---

## 1. Как отображаются участники (активный звонок / канал)

### Тайл

Один человек = один **тайл** (скруглённый прямоугольник на тёмном фоне `#111214` / `#2b2d31`):

- **Только голос** — крупный круглый аватар по центру, имя внизу тайла.
- **Камера** — видео заполняет тайл (`object-fit: cover`), имя поверх / внизу.
- **Self** — такой же тайл «Вы» (часто зеркало камеры), не отдельный PiP поверх всего экрана в актуальном desktop-лейауте Discord для 1:1/малых групп.

### Состояния на тайле

| Состояние | Как видно |
|---|---|
| Молчит | Спокойный аватар / видео без обводки |
| Говорит | **Зелёное кольцо** `#23a55a` вокруг аватара; при видео — зелёная рамка тайла. Источник — реальный уровень громкости (debounce, без «фейковой» пульсации) |
| Mute | Бейдж перечёркнутого микрофона (обычно низ тайла / угол аватара) |
| Deafen | Бейдж наушников; подразумевает mute |
| Стрим / экран | Превью или метка Live; активный шаринг уходит в **hero**-слот |

Self-mute рисуется **сразу** по клику; чужие mute/deafen — с сервера.

### Сетка vs rail

**Без демонстрации экрана**

- 2 человека — два крупных тайла рядом (или 1×2).
- 3–4 — четверти / комфортная сетка.
- 5–9 — плотнее, но читаемо.
- Больше — пол размера + иногда overflow `+N`; активные спикеры могут всплывать.

**С демонстрацией**

```
┌──────────────────────────┬─────────┐
│  экран (hero, main-area) │ rail    │
│                          │ тайлы   │
│                          │ камер / │
│                          │ аватаров│
└──────────────────────────┴─────────┘
         control bar внизу
```

Участники съезжают в правый столбец (~230px) или нижний strip; экран занимает центр. Два экрана — две колонки в main.

**Voice channel без шаринга** у Discord часто оставляет main пустым («посмотрите участников справа / в списке канала»), а люди живут в рейле или в списке под названием канала в сайдбаре. Полная сетка тайлов — когда смотрят сцену / есть видео.

### Панель управления

Низ сцены, круглые кнопки:

Mute · Deafen · (Soundboard / Activities) · Camera · Screen · **Disconnect** (красная)

Mute off = красная/заглушенная кнопка; camera on = зелёный акцент в свежих билдах. Таймер длительности рядом со статусом.

## 2. Исходящий звонок до accept (нажал «Позвонить»)

Именно DM/Group DM, не вход в voice channel.

### Что видит звонящий

1. Сцена звонка **сразу** открывается внутри DM (чат не уезжает в отдельное окно; на desktop панель встроена в колонку переписки).
2. Крупный тайл **собеседника** (аватар), часто рядом / вторым — свой тайл (превью камеры, если video call).
3. Статус-текст: **«Calling…»** / ожидание ответа (не «На линии» и не таймер длительности).
4. Тихий **исходящий** рингтон в цикле.
5. Control bar **уже активен**: можно mute / cam / screen / повесить **до** ответа.
6. Медиа локально уже захвачено (mic; cam если video) — собеседник ещё не в сессии.
7. Пока нет answer — удалённый тайл без живого видео/аудио (только аватар + «Calling…»).
8. Таймаут без ответа → звонок сам гаснет; в чате остаётся системная запись о звонке.

Схема:

```
┌─────────────────────────────────────┐
│         [ аватар callee ]           │
│            Calling…                 │
│         [ ваш тайл / cam ]          │
│                                     │
│   ○ mute  ○ deaf  ○ cam  ○ scr  ●end│
└─────────────────────────────────────┘
         сообщения DM ниже / рядом
```

Ключевой UX-ход Discord: **ринг = та же сцена, что и активный звонок**, только статус и отсутствие remote media. Не отдельный «телефонный» fullscreen на desktop.

### Что не так

Нет отдельного экрана только с огромным аватаром и одной кнопкой «Отмена» без остальных контролов — Discord сразу даёт полный dock. Incoming у callee, наоборот, — компактный диалог Accept/Decline.

## 3. Входящий звонок (для контраста)

У того, кому звонят:

1. Модалка / карточка поверх клиента: аватар с **пульсирующими кольцами**, подпись Incoming Call / Voice / Video, имя.
2. Две главные кнопки: **Decline** (красная) · **Accept** (зелёная).
3. Громкий входящий рингтон + desktop / push notify.
4. Пока не принял — **не** видит полную сцену тайлов звонящего; после Accept — та же сцена, что у caller после connect.
5. На mobile чаще fullscreen; на desktop — карточка (и ответ из Game Overlay).

## 4. Как это ложится на Pulse сейчас

### Участники

| Discord | Pulse |
|---|---|
| Тайл + `is-speaking` зелёный `#23a55a` | `.call__speak-ring` / `.call__tile.has-video.is-speaking` в `globals.css` |
| Сетка без шара | `call__tiles--grid` + `c1`…`c4` (`VoiceOverlay`) |
| Hero экран + rail 232px | `call__stage-body` → `call__main-area` + `call__participants-rail` |
| Mute на тайле | суффикс «· микрофон выкл.» у имени (`VoiceTile` / self в `CallPanel`) |
| Фон сцены | `#111214`, empty main `#0a0a0c` |

Код: `CallOverlay` (`CallPanel`), `VoiceOverlay` (`VoiceStagePanel`, `VoiceTile`), класс `call__stage--discord`.

### Исходящий до accept

| Discord | Pulse |
|---|---|
| Сцена сразу после Call | `startCall` → `setActive({ outbound: true })` → `CallPanel` |
| «Calling…» | Отдельной строки нет: в баре `status \|\| "Звонок"`, пока не станет «На линии» / «Соединение…». Имеет смысл явно ставить **«Звоним…»** на время `ringing` |
| Исходящий ринг | `ringtone.ts` + таймер ~35 с → «Нет ответа» |
| Контролы до ответа | Уже в `CallPanel` (mute / cam / screen / end) |
| Remote ещё нет | Тайл peer с аватаром, `remoteStream` пустой |

Статусы `useCall`: «Соединение…», «На линии», «Нет ответа», «Звонок отклонён», «Переподключение…», QoS и т.д. — см. `setStatus(...)` в хуке.

### Входящий

| Discord | Pulse |
|---|---|
| Карточка + pulse rings | `call__card--incoming` + `.call__ring` (::before/::after pulse) |
| Accept / Decline | `call__btn--ok` / `call__btn--bad` |
| Notify | `notify.ts` + tag `pulse-call-*` |

### Voice channel

Join без ринга → `VoiceOverlay` / свёртка в `VoiceDock` (как нижняя панель Discord). Список в войсе под каналом в сайдбаре — отдельно от сцены.

## 5. Чеклист, если дотягивать UI до Discord

1. **Исходящий ringing:** явный статус «Звоним…» (или «Calling…»), пульс/ожидание на тайле peer, без таймера длительности до connect.
2. **Не путать** с incoming-модалкой: у caller — полная сцена, у callee — карточка.
3. Speaking только от анализатора / ActiveSpeakers, debounce ~300 мс (уже близко: порог 18, hold 320 мс в 1:1).
4. При screen share — всегда hero + rail, не оставлять экран как ещё один равный тайл в сетке.
5. Mute/deafen — иконки-бейджи на тайле, не только текст в подписи (сейчас в основном текстовый суффикс).
6. Mic-first: камера выкл. при старте (уже так).
