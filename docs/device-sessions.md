# Устройства и сеансы

В профиле, на вкладке «Устройства», показаны отдельные входы в аккаунт:
приложение или браузер, ОС, IP, примерное место входа, время входа и последней
активности. Текущий сеанс отмечен. Можно выйти на выбранном устройстве или
завершить все остальные сеансы, сохранив текущий.

Один вход соответствует одному токену: вкладки браузера, использующие один
токен, отображаются вместе. Повторный вход создаёт отдельный сеанс. Сведения
об устройстве определяются по User-Agent и могут быть неполными. Старые сеансы
сохраняются; сведения об устройстве и месте заполняются при переподключении.

IP берётся сервером через `clientAddress`, с существующими ограничениями
`TRUST_PROXY=1`: заголовки доверяются только loopback-прокси. Прокси должен
перезаписывать `X-Real-IP`; иначе будет показан его адрес.

Для публичных IP сервер получает город, регион и страну через HTTPS
[IPWhois](https://ipwhois.io/documentation). Провайдеру передаётся только IP,
без токена, логина и User-Agent. Частные и локальные адреса не отправляются.
Результаты, включая ошибки, кешируются на сутки; кеш ограничен 1000 адресами.
Тайм-аут — 1,5 секунды. При недоступности сервиса вход продолжается, а место
показывается как неизвестное. `SESSION_GEOLOCATION=0` отключает внешние запросы.
Место определяется приблизительно по сети, а VPN может менять отображаемый
город; точный адрес и GPS не собираются. Сохраняется место первоначального
входа, переподключение его не заменяет.

Сведения хранятся в `data/sessions.json`; активность сохраняется не чаще раза
в минуту на сеанс. Срок действия токенов остаётся 30 дней. Список не содержит
токенов других устройств: команды используют отдельные SHA-256 идентификаторы.
Каждая команда повторно проверяет пользователя и принадлежность сеанса.
Удаление сохраняется до уведомления устройства; при ошибке записи откатывается.
Подключённые вкладки отозванного сеанса получают `auth:expired` и отключаются,
а отключённые устройства не смогут восстановить отозванный токен.
