# Обзор продукта

Pulse совмещает две привычные модели:

- **Чаты** — как Telegram: личка, ответы, пересылки, альбомы, голосовые сообщения.
- **Группы** — как Discord: сервер слева, текстовый канал, голосовые комнаты, список участников справа, сцена звонка.

Глобальных «лобби» больше нет: публичные каналы старого типа при загрузке отбрасываются. Всё живёт в ЛС и группах.

## Карта интерфейса

```
┌──────┬─────────────┬──────────────────────────┬────────────┐
│ Rail │  Сайдбар    │     Основная колонка     │ Участники  │
│ 72px │  каналы /   │  чат  или  сцена звонка  │  (группа)  │
│      │  инбокс ЛС  │                          │            │
│      ├─────────────┤                          │            │
│      │ Voice dock  │                          │            │
└──────┴─────────────┴──────────────────────────┴────────────┘
```

- **Server rail** (`ServerRail`) — кружки как в Discord: Pulse (инбокс), Люди, группы, «+».
- **Сайдбар** зависит от фокуса:
  - `home` — только личные чаты (как список диалогов в Telegram);
  - `dms` — люди / поиск;
  - группа — `#general` + голосовые каналы;
  - `create` — создание группы.
- **Правая колонка** (`GuildMemberList`) — владелец / в сети / не в сети. Только в группе.
- **Voice dock** — полоска внизу сайдбара, когда голосовой канал свёрнут (как панель Discord).

Полноэкранная сцена звонка открывается поверх чата и использует тот же Discord-лейаут, что и голосовой канал: тёмная сцена `#111214`, участники справа, экран — в центре.

## Два вида голоса

| | Личный звонок | Голосовой канал группы |
|---|---|---|
| Аналог | Telegram / Discord DM call | Discord voice channel |
| Где | из шапки ЛС | клик по каналу в группе |
| Транспорт | всегда P2P WebRTC | всегда свой LiveKit SFU на ВМ |
| Deafen | да (наушники) | да |
| Несколько комнат | один звонок на пользователя | один канал на пользователя |
| Конфликт | нельзя одновременно быть в канале и в звонке | то же |

Подробности — в [voice.md](./voice.md).

## Ограничения продукта

- Группа: до **50** участников, до **20** голосовых каналов.
- LiveKit room: до **12** участников (конфиг SFU).
- Создатель группы не может из неё выйти — только удалить.
- Канал «Общий» удалить нельзя.
- Шумодав — Krisp, иначе RNNoise, иначе браузерный NS (см. [voice.md](./voice.md#шумоподавление)).
