# Чаты как Telegram

Личка и лента сообщений сознательно ближе к Telegram, а не к Discord: инбокс диалогов, ответы с превью, альбомы, голосовые кружки, галочки прочтения.

## Личные сообщения

- Id комнаты стабильный: `dm_{minId}_{maxId}` (`src/lib/rooms.ts`).
- Пустой диалог виден только тому, кто его открыл (`visibleTo`).
- Нельзя написать себе.
- Из шапки ЛС — аудио/видеозвонок (`useCall`). Это не голосовой канал группы.

Инбокс (`sidebarPanel === "home"`) показывает **только DM**. Группы живут в server rail, как серверы Discord.

## Сообщения

Типы (`ChatMessage.kind`): `text` | `system` | `file` | `call` | `invite`.

| Фича | Поведение |
|---|---|
| Ответ | превью автора + текст, прыжок к исходнику |
| Пересылка | `message:forward` в другой чат |
| Редактирование | `editedAt`, только своё |
| Удаление | томбстоун у собеседников / полное у себя по политике сервера |
| Пин | одно закреплённое на чат |
| Реакции | emoji + список `userIds` |
| Альбом | `files[]`, `file` дублирует первый (как Telegram media group) |
| Голосовое | отдельный `VoiceBubble` (waveform) |
| Инвайт в группу | карточка в ЛС: принять / отклонить |
| Лог звонка | системное `kind: "call"` после 1:1 звонка |

Оптимистичная отправка: `clientKey` не даёт списку прыгать, когда сервер подменяет id.

## Композер

`Composer`: автовысота, черновики (`src/lib/drafts.ts`), вложения (drag / paste / picker), emoji, `@mentions` (`MentionMenu`), запись голоса свайпом как в Telegram (`VoiceRecorderBar`).

Запись голоса тоже идёт с `echoCancellation` / `noiseSuppression` / `autoGainControl` — чтобы в заметке не было комнатного гула.

## Статусы и присутствие

- Typing — `typing` в текущую комнату.
- Online / last seen — люди в директории и в guild roster.
- Прочтение: `peerReadAt` → одна / две галочки на своих пузырях.
- Непрочитанные считаются от last-read; «Прочитать все» в инбоксе.

## Люди и поиск

Вкладка «Люди» в rail: поиск пользователей, открытие ЛС. Публичные группы ищутся отдельно (`searchPublicGroups`) и джойнятся без инвайта.

## 1:1 звонки

Не канал, а сессия между двумя userId.

1. `call:invite` (audio | video), таймаут ринга **35 с**.
2. Кто-то занят (`callByUser`) — отказ. Голосовой канал тоже считается занятостью.
3. SDP/ICE через `call:signal`, медиа — P2P (`useCall`).
4. Камера и экран поднимаются по жесту, старт всегда с микрофона.
5. Рингтон (`src/lib/ringtone.ts`), системный notify, запись в чат через `call:log`.
6. ICE restart до 3 раз с паузой 1.6 с.

UI — `CallOverlay` с тем же классом `call__stage--discord`, что и групповой голос: плитки, speaking-кольцо, демонстрация в центре.

Референс Discord (участники + исходящий «Calling…» до accept) — [discord-call-ui.md](./discord-call-ui.md). Медиа и шумодав — [voice.md](./voice.md).

## Уведомления

- Звук сообщения, если вкладка в фоне (`src/lib/notify.ts`).
- Web Push (`src/server/push.ts`) + service worker.
- Входящий звонок — отдельный notify с тегом, чтобы не копить карточки.
