# Группы как Discord

Группа Pulse — это **сервер (guild)**, не групповой чат Telegram. У неё есть иконка в левом rail, текстовый канал, голосовые комнаты и правый список участников.

## Зачем так

В Telegram группа = один тред. В Discord сервер = набор каналов. Pulse берёт вторую модель:

- один текстовый канал на группу (`#general` — это сам `ChatInfo` группы);
- N голосовых каналов;
- участники всегда видны справа;
- голос живёт отдельно от переписки: можно сидеть в войсе и листать другой чат.

## Создание и доступ

`createGroup(ownerId, title, topic, _, visibility)` в `src/server/chats.ts`.

- Название до 40 символов, топик до 120.
- Id: `group_{slug}` или со случайным суффиксом при коллизии.
- Сразу создаётся голосовой канал **«Общий»** (`{id}::voice_general`).
- `visibility`: `public` | `private` (старые группы без поля = private).
- Публичную можно найти и вступить (`group:join` / `joinPublicGroup`). Ошибка для приватной намеренно общая: «Группа не найдена».
- Приватная — только по инвайту.

Лимит: **50** человек.

## Инвайты

Любой участник шлёт `group:invite` → в ЛС цели приходит сообщение `kind: "invite"` с карточкой.

- Принять (`group:invite:respond`) → `addGroupMember`.
- Отклонить / истечь — статус на карточке.
- Уже состоит — ошибка «Уже в группе».

Это ближе к «ссылка-приглашение в ЛС», чем к Discord vanity-invite, но вход в гильдию тот же: стал `memberIds` — видишь сервер в rail.

## Роли

Отдельных ролей нет. Есть **создатель** (`createdBy`):

| Действие | Кто |
|---|---|
| Переименовать, топик, аватар, public/private | создатель |
| Удалить группу | создатель |
| Удалить голосовой канал (кроме «Общий») | создатель |
| Создать голосовой канал | любой участник |
| Пригласить | любой участник |
| Выйти | любой **кроме** создателя |

Создатель выйти не может: «удалите группу». Системные/protected чаты не меняются.

## UI гильдии

### Server rail

`ServerRail`: вертикаль 72px, орбы 48px, активный индикатор слева (`layoutId="server-rail-active"`), бейдж непрочитанных. Группа с аватаром — фото без scale (чтобы не мылить), без аватара — инициалы.

Фокус rail:

- `home` — инбокс ЛС
- `dms` — люди
- `{groupId}` — сайдбар этой гильдии
- `create` — форма новой группы

### Сайдбар гильдии

`ChatSidebar` при `activeGuild`:

```
Текстовые каналы
  # general          ← открывает chat.id группы

Голосовые каналы  [+]
  🔊 Общий
      аватар  имя  🔇
  🔊 Другой канал
```

Участники в войсе рисуются **под каналом**, как в Discord: speaking-класс, иконка мута. Клик по каналу = `voice:join` (повторный клик по своему — не реджойнит).

«+» создаёт канал (до 20). Escape закрывает форму.

### Список участников

`GuildMemberList` справа:

1. Владелец
2. В сети
3. Не в сети

Клик по человеку открывает ЛС (и сбрасывает guild-сайдбар в инбокс). Presence синкается с глобальным `people`.

## Голосовые каналы — данные

```ts
type VoiceChannelMeta = { id: string; title: string; createdAt: number };
type VoiceChannelUser = {
  userId; name; muted; deafened; speaking?;
  avatarUrl?; cameraOff?; sharingScreen?; mediaRevision?;
};
```

Сервер рассылает `voice:state` всем членам группы: список каналов + кто внутри. Клиент сайдбара и оверлея питается этим снимком.

Удаление канала: LiveKit-комнату гасят, presence чистят, «Общий» и последний канал трогать нельзя.

Как устроен сам звонок в канале — [voice.md](./voice.md).
