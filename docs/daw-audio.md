# Звук REAPER / FL Studio с ASIO

**Maiko DAW Bridge** — встроенный VST3 для Windows x64. Он копирует мастер-канал до вывода в ASIO. Аппаратный Loopback и виртуальный аудиокабель не нужны; драйвер и локальное прослушивание остаются в DAW. Микрофон звонка работает отдельно.

## Установка

1. В личном звонке или голосовом канале нажмите кнопку демонстрации. В **окне выбора экрана или приложения** справа нажмите **«Скачать VST3»**. Кнопка автоматически установит плагин в `%LOCALAPPDATA%\Programs\Common\VST3`, без прав администратора. ZIP, инструкция и файлы в загрузках не создаются: копируется только нативный модуль в стандартную структуру VST3.
2. После проверки установленного файла кнопка заменится на **«✓ Установлено»**. При повторном открытии окна проверяется совпадение с версией плагина в приложении. Если файл занят открытой DAW, старый плагин сохраняется: закройте DAW и повторите установку.
3. Пересканируйте плагины в DAW; при необходимости добавьте `%LOCALAPPDATA%\Programs\Common\VST3` в пути VST3. В REAPER: Preferences → Plug-ins → VST → Re-scan. В FL Studio: Options → Manage plugins → Plugin search paths → Find installed plugins.
4. Добавьте **Maiko DAW Bridge** последним эффектом на **Master**. Достаточно одного экземпляра на мастер-канале каждого процесса DAW. Установка плагина не изменяет проект DAW.

В окне выбора справа рядом с кнопкой VST3 стоит подпись **«Для передачи звука DAW такие как FL studio»**. Кнопки «Отмена» и «Поделиться» слева на той же строке. Блок с заголовком и развёрнутая инструкция убраны; кнопки VST3 в панели звонка нет.

## Автоматический звук

В Майко выберите экран или окно и отметьте передачу звука. Отдельного выбора источника звука больше нет.

- **Весь экран:** звук ПК и ASIO-звук работающих DAW; собственное воспроизведение Майко исключается.
- **Окно DAW:** звук выбранного приложения и его дочерних процессов, в том числе через VST. Другие DAW не подключаются.
- **Окно другой программы:** звук только этой программы. Работающие DAW не добавляются.
- **Звук выключен / собственное окно Майко:** мосты не подключаются.

VST можно добавить уже после запуска демонстрации. Приложение постоянно ищет подходящие мосты и подключает их к существующей аудиодорожке. Удаление и повторное добавление плагина не требуют перезапуска демонстрации или WebRTC-соединения. После исчезновения моста дорожка остаётся активной: для окна восстанавливается штатный захват звука приложения, при ASIO до возвращения моста будет тишина.

Весь экран использует штатный звук Windows. Чтобы не удваивать мастер при совместном драйвере, мост такого процесса приглушается, если Windows сообщает об активной render-сессии этого DAW. Для окна при поступлении блоков VST предпочтение отдаётся мосту. Вывод DAW напрямую на ASIO не проходит через микшер Windows и передаётся через плагин.

Windows разделяет звук по процессам, а не по проектам DAW: другие окна того же процесса могут попадать в захват. Размещайте мост именно на Master, поскольку Майко не определяет назначение FX-слота. Если DAW останавливает обработку при потере фокуса, отключите соответствующую настройку аудиодвижка (например, Auto close в FL Studio).

## Интерфейс плагина

Голубой объёмный индикатор реагирует на мастер-сигнал; шкалы **L/R** показывают уровень в dB. Состояния: **«Ожидание демонстрации»**, **«Подключено · тишина»**, **«Звук передаётся»**. Индикатор подключения относится к этому экземпляру VST и его локальному приёмнику. Доставку конкретному собеседнику он не подтверждает.

Заголовок редактора: **«Майко»**, ниже **«Мост DAW»**. Дополнительные подписи про Master и ASIO в редакторе убраны.

Мост работает в настольном приложении. Браузерная версия не имеет доступа к его локальному приёмнику. Кнопка скачивания появляется в Windows-приложении с поддержкой моста.

## Сборка и проверка

Для сборки исходников нужны Rust MSVC и Visual C++ Build Tools / Windows SDK. В готовом приложении они не требуются. `node desktop/prepare-native.cjs` собирает плагин и помощники Windows. Нативный VST3 включается в установщик приложения; ZIP не собирается и не включается.

```powershell
npm --prefix desktop test
npm --prefix desktop run test:daw-audio
npm --prefix desktop run test:screen-audio
```

Сквозной тест загружает настоящий VST3 в изолированный хост и проверяет DLL → named pipe → Electron → AudioWorklet → stereo Opus / WebRTC, вставку после создания отправителя, удаление / повторное подключение, паузу, изоляцию окон, установку из окна выбора демонстрации, клонирование и остановку. Проверяются 32-/64-битный passthrough, 44,1 / 48 кГц и отрисовка нативного редактора. Отдельный `node desktop/tests/daw-install.cjs` проверяет установку единственного модуля, отсутствие загрузок, статус при открытии picker, реальную блокировку DLL загруженным VST-хостом и повторную установку после его закрытия. Сохраняются только спектральные уровни и изображения тестового редактора; записи звука и кадры рабочего стола не сохраняются. Проверка в минимальном хосте не заменяет ручную проверку конкретной версии REAPER / FL Studio и ASIO-драйвера.

Аудиопоток VST не выполняет I/O, не выделяет память и не ждёт приёмник: передача идёт через ограниченную SPSC-очередь и отдельный worker. Named pipe доступен владельцу процесса и SYSTEM; удалённые подключения запрещены. Приём открывается только во время выбранной демонстрации со звуком. Навигация основного медиадокумента и остановка демонстрации закрывают соединения. Серверы звонков и coturn не меняются.

Ограничения штатного захвата: [Microsoft Loopback Recording](https://learn.microsoft.com/en-us/windows/win32/coreaudio/loopback-recording). Интерфейсы: [vst3-rs 0.3.0](https://docs.rs/vst3/0.3.0/vst3/).
