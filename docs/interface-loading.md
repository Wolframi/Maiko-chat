# Загрузка интерфейса по необходимости

Чат больше не загружает SDK LiveKit и закрытые тяжёлые панели при запуске.
Входящие личные звонки и управление медиасессиями остаются доступны сразу.

## Что изменилось

- LiveKit загружается при первом входе или восстановлении голосового канала,
  параллельно с запросом токена. Модуль и выполняющийся запрос разделяются
  между потребителями; неудачную загрузку можно повторить при следующем входе.
  Выход из канала отменяет ожидающее подключение, не отменяя загрузку для других.
- Панели профиля, сведений о чате, просмотра медиа/паков, звонка и голосового
  канала монтируются при первом использовании. GIF, стикеры и эмодзи загружаются
  при выборе вкладки. Редакторы аватара, стикера и рингтона — при открытии редактора.
- После первого открытия панели остаются смонтированными: сохраняются состояние
  и анимации закрытия. Анимации ленивых компонентов изолированы от родительских,
  чтобы поздняя загрузка вкладки не удерживала закрытую панель в DOM.
- Во время загрузки виден короткий индикатор. Ошибка необязательного чанка
  показывает «Повторить» и не уничтожает чат или черновик сообщения.
- `CallAlerts` содержит входящий вызов, кнопки ответа/отклонения, рингтоны и
  аудиоэлемент. Они работают без загруженной панели камер и демонстраций.
  Обработчики Socket.IO и хуки звонков остаются подключены с начала сессии.
- Постоянный медиадокумент Electron использует тот же загрузчик SDK; управление
  дорожками и версия протокола `maikoMediaRuntime` не изменены.

## Измерения

Windows, Chromium 151.0.7922.34, Node.js 24.14.1. Проверена локальная
production-сборка с защитой JavaScript: изолированный сервер, авторизованный
пользователь, 1280×900, уменьшенное движение, без ограничения CPU/сети.
Три новых браузерных контекста для каждого варианта. JS считается через
Resource Timing через секунду после появления `.workspace`; панели не открываются.

| Метрика | До | После |
|---|---:|---:|
| Переданные тела JS, сжатые, байт | 724 528 | 495 506 |
| JS после распаковки, байт | 2 500 199 | 1 654 761 |
| Запросы JS | 20 | 14 |
| Появление рабочего интерфейса, медиана | 1540 мс | 1365 мс |
| Время исполнения JS, медиана CDP ScriptDuration | 241 мс | 211 мс |

Объём передаваемого JS снизился на **31,6%**, распакованного — на **33,8%**.
В этом прогоне интерфейс появился примерно на **175 мс (11%)** раньше.
Все три отсчёта появления: до — 2605/1540/1502 мс, после — 1528/1365/1323 мс.
Малое число запусков, локальный сервер и колебания планировщика не позволяют
обещать такое же ускорение каждому пользователю. При открытии функции её
отложенные чанки всё равно скачиваются; суммарный объём всех функций не исчезает.
Это оптимизация запуска, не измерение FPS или качества звонка.

Отдельное сравнение esbuild (без Next.js/обфускации) подтверждает границы импорта:
начальная статическая часть ChatApp — 1 501 735 → 836 889 байт; DesktopMediaHost —
769 925 → 246 046 байт. LiveKit отсутствует в обоих начальных наборах модулей.
Эти числа нельзя подменять сетевыми метриками production-сборки из таблицы.

## Проверки

- Production-сборка, TypeScript и защита 22 JS-чанков прошли.
- 113 модульных тестов сайта прошли; 3 MongoDB-теста без отдельной БД пропущены.
- Браузером проверены загрузка при первом открытии, повторное открытие без
  нового скачивания, ошибка чанка и повтор с сохранением черновика, вкладки
  эмодзи/GIF/стикеров и закрытие панели.
- Проверены отсутствие SDK в простое, повтор после неудачной загрузки, отмена
  при зависшей загрузке, создание настоящего класса Room с локальной заглушкой
  транспорта и освобождение комнаты. Последнее не заменяет проверку с реальным SFU.
- Реальный P2P-звонок двух локальных пользователей прошёл при искусственно
  задержанной загрузке UI звонка: доступны ответ, входящий сигнал, удалённая
  аудиодорожка, сворачивание, mute и отправка сообщений.
- Прошли сценарии восстановления голосовой сессии, разделения подписок состояния
  и 9 проверок шумоподавления/непрерывности звука. В сумме 27 браузерных сценариев.

Полный внешний групповой звонок через рабочий SFU в этой проверке не выполнялся.
Изменения опубликованы на сервере 30 октября 2026 года вместе с постоянным кешем
переписок, сборка `86689dde-f2b5-4b4a-bcca-39505093adfb`. Отдельный выпуск EXE
для обновления интерфейса не требуется; сведения — в [истории публикаций](deployment.md).

## Повторить замеры

Из `site/`:

```powershell
node scripts/measure-client-bundle.mjs current
npm run build
node --import tsx scripts/measure-interface-startup.mts current
node node_modules/playwright/cli.js test e2e/deferred-loading.spec.ts e2e/deferred-panels.spec.ts e2e/chat-runtime.spec.ts e2e/voice-resume.spec.ts e2e/state-subscriptions.spec.ts e2e/noise-filter.spec.ts --workers=1
```

Браузерные проверки и замеры запуска выполняются после завершения сборки:
изолированные серверы используют готовую `.next` через junction.
Для сравнения времени запуска не запускайте параллельно сборку и другие тесты.
Все отсчёты и списки модулей сохраняются в `output/interface-loading/`
(`before/after-bundle.json`, `before/after-startup.json`); каталог игнорируется Git.
