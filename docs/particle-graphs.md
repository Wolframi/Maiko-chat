# Заранее рассчитанный граф частиц

Сайт и локальная заставка Electron загружают готовый граф соседей вместо его
построения при запуске. Геометрия, плотность и алгоритм движения сохранены.
Для `hiphop` и `samba` включены варианты на 7 000, 14 000, 40 000 и 84 000 точек:
отдельный граф нужен для каждой плотности, потому что декодер меняет выборку точек.

## Загрузка и кеш

- Бинарные файлы находятся в `site/public/particles/`, описание ресурсов —
  в `site/src/lib/maikoParticleGraphAssets.ts`. URL содержит SHA-256 содержимого.
  HTTP передаёт gzip с годовым `immutable`-кешем.
- Первый HTML предварительно загружает граф выбранной модели: 40 000 точек
  при ширине меньше 600 px, иначе 84 000. `media` исключает загрузку второго
  варианта. В React граф загружается параллельно с моделью.
- В одном документе используются общий Promise и кеш проверенных графов.
  Каждый рендерер получает собственный массив; отмена одного потребителя
  не прерывает общую загрузку.
- Модель определяется по размеру и CRC32 полных исходных байтов. CRC32 графа,
  версия формата, число точек, точный `contact`, длина файла и индексы соседей
  проверяются перед использованием. CRC32 обнаруживает случайное повреждение
  и устаревшие данные; это не криптографическая аутентификация.
- Неизвестная модель/плотность, ошибка или повреждённый файл используют прежний
  Rust/WASM → JS путь. Ожидание графа после декодирования ограничено 150 мс,
  фоновой загрузки — 4,5 с. Загрузка WASM начинается только при резервном расчёте.
- Electron упаковывает те же бинарные данные и читает их локально через IPC.
  Допускаются только две известные модели и четыре значения плотности.
  Сайт внутри Electron также получает графы из локального набора ресурсов.

## Обновление данных

```powershell
npm --prefix site run particles:precompute
npm --prefix site run particles:prepare
```

Первая команда считает графы исходным JS-алгоритмом и записывает `.bin`, `.bin.gz`,
манифест и `site/native/particle-graph/precomputed.json`. Rust для неё не нужен.
Эти файлы нужно включать в репозиторий вместе с изменёнными исходниками/моделями.
Обычные `dev/build/start` и подготовка ресурсов Electron проверяют хеши моделей,
исходников, бинарных данных и сжатых копий, не пересчитывая граф.
После изменения модели, декодера, алгоритма графа или бинарного формата выполните
первую команду повторно. Сборка с устаревшими артефактами завершается ошибкой.

## Замер

```powershell
npm --prefix site run bench:particles
```

Отчёт сохраняется в `output/particle-data/benchmark.json`.
Замер 29 октября 2026: Windows, Intel Core i5-7600, Chromium 151, семь отсчётов,
медиана, 84 000 точек. Холодная загрузка использует новый контекст браузера,
повторная навигация сохраняет только HTTP-кеш, затем измеряется кеш в памяти.

| Модель | gzip, байт | Первый запрос, мс | HTTP-кеш, мс | Память, мс | Текущий Rust-расчёт, мс |
|---|---:|---:|---:|---:|---:|
| hiphop | 667 304 | 28,7 | 21,2 | 0,5 | 359,8 |
| samba | 665 716 | 29,7 | 21,2 | 0,6 | 312,8 |

Время загрузки включает запрос графа, распаковку gzip, проверку модели и графа,
декодирование графа и выдачу независимой копии. HTTP-сервер локальный: задержка
и пропускная способность внешней сети не измерялись. Модель уже загружена;
её декодирование, настройка GPU, анимация и полный запуск приложения исключены.
Rust измеряется с уже загруженным модулем и прежними паузами для интерфейса.
Это сравнение этапа подготовки графа, не времени запуска всего приложения.
Первый запрос добавляет около 666–667 КБ сети; в рабочем интерфейсе он идёт
параллельно с загрузкой модели. Полный несжатый граф занимает 1 008 024 байта.

Проверки покрывают точное совпадение всех восьми графов с текущим алгоритмом,
загрузку и кеш, отмену, повреждение, таймаут, изменённую модель, нестандартную
плотность, оба размера экрана и локальную упаковку Electron.

Production-сборка и проверка защиты JS прошли. На собранном Next.js-сервере
подтверждены `Content-Encoding: gzip`, `application/octet-stream`, годовой
`immutable`-кеш и правильные декодированные байты обеих полных моделей.
Electron-проверка запуска подтвердила `maiko-graph-precomputed` без вызовов
Rust/JS, три секунды локальной анимации и отсутствие обязательного ожидания
при уменьшенной анимации.
