# Рабочий сервер Майко

Сайт: https://maiko.galacticvps.qzz.io. VPS: `179.254.175.134`.

Исходники и Git находятся в `/root/maiko`, приложение — в `/root/maiko/site`.
PM2 запускает `site/server.ts` с `--import tsx` через корневой
`ecosystem.config.cjs`; имя процесса — `pulse-chat`. Nginx направляет запросы
на `127.0.0.1:3000`. Сборка выполняется командой `npm run build` из корня.

Настройки скопированы в исключённые из Git файлы с правами `600`.
`site/data/` и `site/uploads/` ссылаются на существующие каталоги
`/root/pulse-chat/data/` и `/root/pulse-chat/uploads/`. Старый каталог нельзя
удалять целиком: в нём остаются рабочие данные и предыдущая версия для отката.
Сообщения находятся в MongoDB, медиа — в S3. Ежедневное резервное копирование
MongoDB продолжает работать.

При обновлении 11 октября 2026 года новая версия собрана и протестирована
отдельно от работающего сайта. Резервные копии исходников, настроек, конфигурации
PM2 и данных находятся в `/root/maiko-backups/cleanup-*`; путь последней копии
записан в `/root/maiko-cleanup-backup-path`. MongoDB также скопирована штатным
скриптом. После переключения проверены все 519 сообщений, 10 аккаунтов,
health check сайта и сервиса LiveKit.

Автообновление через timer и webhook остаётся отключённым: установленный
автодеплой требует адаптации к структуре `site/`. Ручное обновление по SSH:
`scripts/deploy.ps1`; он упаковывает только закоммиченные файлы через `git archive`.
Пароли и ключи доступа в репозитории не хранятся.

Обновления Windows-приложения обслуживаются Nginx через публичный HTTPS-путь
`/desktop-updates/` из `/var/www/maiko-desktop-updates/`. В нём публикуются только
установщик, blockmap и `latest.yml`; исходники и настройки доступа остаются закрыты.
Публикуйте метаданные последними. Подробности — в [desktop-updates.md](desktop-updates.md).
