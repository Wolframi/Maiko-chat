Майко 1.1.16

- Исправлены белые полосы при изменении размера окна.
- Убраны скачки интерфейса при изменении высоты и достижении минимального размера окна.
- Оболочка и вложенный интерфейс используют непрозрачный тёмный фон во время перерисовки.

Майко 1.1.15

- Подтверждение удаления стикеров и паков оформлено в стиле приложения.
- Кнопка удаления стикера увеличена и доступна с клавиатуры и на сенсорных экранах.
- В установщик включён обновлённый интерфейс сайта.
- При обновлении интерфейса демонстрация и звонки продолжают работать в отдельном медиадокументе.
- Обновление устанавливается из закрытого S3 с проверкой SHA-512 и автоматическим запуском приложения.

Майко 1.1.14

- Расширены области изменения размера по всем краям и углам окна.
- В Windows перетаскивание отслеживается и над содержимым сайта, и за пределами окна.
- Отменённые скачивания сразу исчезают из последних загрузок и не вытесняют сохранённые файлы из списка из 15.
- Это переходное обновление доступно с сервера; последующие установщики и blockmap скачиваются напрямую из закрытого S3-бакета по временным ссылкам.
- Сохранены electron-updater, скачивание изменённых блоков, проверка SHA-512 и автоматический запуск после установки.
- Наличие обновления проверяется при запуске и каждые 30 минут; после публикации сервер уведомляет открытые приложения через WebSocket.
- Сертификат подписи Windows пока не настроен; проверка издателя включится после выпуска подписанного приложения.
