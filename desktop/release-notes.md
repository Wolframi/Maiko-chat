Майко 1.1.11

- Во время скачивания обновления можно продолжать пользоваться мессенджером.
- После скачивания интерфейс автоматически перезагружается в том же окне с обычным экраном запуска. Кнопка «Установить» больше не нужна.
- Окно и процесс приложения остаются открытыми. Скачанная версия EXE устанавливается без диалогов при обычном закрытии; приложение не запускается повторно само.
- Следующий обычный запуск использует новый EXE. Вход и настройки окна сохраняются.
- Если интерфейс не удалось перезагрузить, можно повторить попытку без скачивания установщика заново.

Для перехода с 1.1.9 нужен новый установщик: прежний GitHub-источник обновлений недоступен без авторизации. Начиная с 1.1.10 используется сервер Майко.
