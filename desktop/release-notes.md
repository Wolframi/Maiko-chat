Майко 1.1.10

- Исправлено получение обновлений: приложение использует HTTPS-сервер Майко, доступный без входа в GitHub.
- После успешной проверки текущей версии в верхней панели появляется «Обновлено».
- Проверка, скачивание с процентами, готовность к установке и ошибки показывают отдельные состояния. Ошибку подготовки установки можно повторить без повторного скачивания.
- Добавлены список скачиваний, открытие папки и сохранение исходных имён файлов.
- Удалены устаревшие ресурсы сайта.

Поскольку прежний источник обновлений недоступен без GitHub-авторизации, версию 1.1.9 нужно один раз заменить новым установщиком. Следующие версии используют исправленный источник. Вход и настройки окна сохраняются.
