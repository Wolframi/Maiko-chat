Сайт и приложение Electron разделены по папкам.

В настройках Windows-приложения появились обновления из GitHub Releases: автоматическая проверка новых версий, скачивание с прогрессом и установка после нажатия «Перезапустить и установить».

Для автоматических обновлений используйте **Maiko-Setup**. Portable-версия обновляется заменой EXE. Предыдущую версию без встроенного обновления нужно один раз заменить новой вручную; вход и адрес сайта сохраняются.
