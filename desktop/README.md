# Майко для Windows

Electron-приложение находится отдельно от сайта в `desktop/`. Своя верхняя панель, сворачивание, разворачивание, изменение размера со всех восьми краёв и углов, плавное скругление окна (включая Windows 10), сохранение положения окна и сеанса. Демонстрация открывает выбор экрана или окна; передача звука включается отдельно.

Окно использует прозрачный фон и сглаживание GPU вместо ступенчатой маски `setShape`. Изменение размера выполняют собственные области захвата: у левой, правой и нижней сторон одинаковый тёмный отступ 6 px. Разворачивание занимает рабочую область выбранного монитора; восстановление возвращает прежний размер и положение. Перед первым показом `native/window-animations.cs` возвращает окну стиль `WS_CAPTION`, который Electron отключает у прозрачных окон. Одновременно `DWMWA_NCRENDERING_POLICY = DWMNCRP_DISABLED` отключает белую системную подложку, которую этот стиль добавлял под прозрачными углами. `WS_THICKFRAME` остаётся выключенным. Системное сворачивание и восстановление учитывают настройки визуальных эффектов Windows.

Рабочая область ограничена высотой окна. История сообщений, список чатов и длинный текст прокручиваются отдельно; поле ввода и отправка остаются доступны при уменьшении, в том числе во время звонка и с вложениями. Форма входа и настройки соединения также прокручиваются, если не помещаются. `prepare-assets.cjs` копирует `src/app/styles/viewport.css` в локальный `ui/site-layout.css`: приложение применяет его при каждой загрузке сайта, поэтому обновлять сервер для этих исправлений не требуется.

При ширине страницы до 1100 px участники группы появляются в боковой панели под «Пригласить», а при расширении возвращаются вправо. Сохраняются владелец, онлайн-статусы и открытие профиля/чата; список прокручивается вместе с каналами. Для предыдущего онлайн-фронтенда `ui/compact-members.js` создаёт копию списка в изолированном мире Electron, не перемещая DOM, которым управляет React. Копия обновляется при изменении участников и группы; новый фронтенд со своим адаптивным списком автоматически отключает эту подстановку.

При изменении размера движение передаётся сразу, без ожидания кадра оболочки. Область сайта меняет размер перед внешним окном, фон нативного контейнера закрывает ещё не перерисованные пиксели, а скругление и состояние панели обновляются только при фактическом изменении. Локальный `ui/site-window.css` задаёт высоту через `100dvh`, поэтому отложенный обработчик `visualViewport` старого сайта не оставляет полосы и не вызывает скачок высоты после перетаскивания. Статус «Подключено» находится в самой верхней панели приложения; повторный статус в заголовке мессенджера и всплывающий баннер скрываются локальным стилем. Темы чатов и статусы собеседников сохраняются. Значок окна задаётся PNG, а `prepare-icons.cjs` создаёт ICO с размерами 16–256 px для ресурсов EXE, ярлыков и установщика.

При показе всего экрана передаётся звук ПК, исключая воспроизведение Майко: голоса собеседников, аудио их демонстраций и уведомления не возвращаются в звонок. При показе окна передаётся только звук приложения-владельца и его дочерних процессов. Windows разделяет звук по приложениям, поэтому другие окна/вкладки того же приложения могут попадать в его звук. Для отдельной вкладки браузера используйте выбор вкладки на сайте в браузере. Собственное окно Майко и источники без определённого владельца передаются без звука. Собеседников по-прежнему слышно локально.

Иконка desktop-версии использует гладкий полноразмерный рисунок `assets/icon-source.png`, а не увеличенный веб-фавикон. PNG для окна и верхней панели — 1024 px; ICO содержит размеры 16, 20, 24, 32, 40, 48, 64, 96, 128 и 256 px, вычисленные непосредственно из исходника. Значок встроен в `win-unpacked/Maiko.exe`, portable и установщик, и дополнительно находится рядом с распакованным EXE как `Maiko.ico`. После сборки Windows получает уведомления об изменении этих конкретных EXE, чтобы обновить прежний значок в Проводнике. Исходный промпт и сведения об иллюстрации: `assets/icon-generation.md`.

Изоляция выполняется нативным WASAPI process loopback, до WebRTC и кодирования. Нельзя подменять его общим `loopback`: это снова захватит звонок и все приложения. Electron закреплён на 44.7.0; его нативный обработчик допускает объект аудиоустройства `{ id, name }`. Используются `loopbackWithoutChrome` для экрана и `applicationLoopback:<PID>` для окна. `native/window-processes.cs` — небольшой помощник, который только сопоставляет HWND выбранного окна и PID (включая UWP); собирается штатным .NET Framework Windows и поставляется в EXE, без установки драйверов. Ошибка определения владельца не включает общий звук ПК. В Windows 10 Chromium не отражает эту нативную изоляцию в `restrictOwnAudio`, поэтому отдельный sandbox-preload добавляет фактически применённую политику к метаданным полученных треков. Он не изменяет аудио и не даёт сайту доступ к Node.js или управлению окном.

## Запуск на этом компьютере

Двойной щелчок по **`Запустить Майко.cmd`** в корне проекта. При первом запуске установятся недостающие зависимости. Нужны Node.js 22.12+ и интернет для установки. Окно терминала не остаётся открытым.

Приложение подключается к уже запущенному Майко на `127.0.0.1:3000`. Если сервера нет, запускает существующий `server.ts` в отдельном процессе Electron. При наличии `.next/BUILD_ID` использует production-сборку, иначе запускает разработку. Для обновления production-интерфейса после правок выполните `npm run build`. Сервер, который запустило приложение, завершится при выходе; уже работающий сервер продолжит работу.

Команды из корня проекта:

```powershell
npm ci --prefix desktop
npm run desktop
# принудительно использовать dev-сервер, если готовой сборки не нужно:
npm --prefix desktop start -- --dev
```

Порт задаётся в `desktop/config.json` (`localPort`) или `MAIKO_LOCAL_PORT`. Локальный сервер сохраняет данные и загрузки в исходной папке проекта. LiveKit для групповых голосовых каналов, TURN и внешние сервисы настраиваются так же, как для сайта; Electron не заменяет эти серверы.

## Подключение к онлайн-сайту

Двойной щелчок по **`Майко онлайн.cmd`** или `npm run desktop:remote`.

По умолчанию используется `https://maiko.galacticvps.qzz.io` — действующий адрес сайта (старый `193.233.247.171.sslip.io` перенаправляет на него). Кнопка настройки в верхней панели позволяет изменить адрес. Разрешён HTTPS и HTTP для localhost. Неверные сертификаты не обходятся.

Адрес по умолчанию для новых установок меняется в `desktop/config.json` перед сборкой. Для разового запуска можно задать `MAIKO_DESKTOP_URL`. Настройка пользователя хранится в `%APPDATA%/Maiko/desktop-settings.json`, сеанс — в отдельном постоянном профиле Electron. Журнал запуска: `%APPDATA%/Maiko/desktop.log`.

## Готовые EXE

```powershell
npm run desktop:build
```

Результат в `desktop/release/`:

- `Maiko-Setup-1.1.7.exe` — установщик с ярлыком рабочего стола и меню «Пуск».
- `Maiko-Portable-1.1.7.exe` — запускается без установки.
- `win-unpacked/Maiko.exe` — распакованная версия.
- `win-unpacked/Maiko.ico` — отдельный файл значка для ярлыков; тот же значок встроен в EXE.

Готовые EXE подключаются к онлайн-сайту и не требуют Node.js, исходников или запущенного сервера на компьютере пользователя. Анимации WebM/MP4, изображения, модели Майко, DTLN/WASM и аудиопроцессоры включены в приложение. Сборка также включает CSS, JavaScript и шрифты текущего сайта. Эти файлы обслуживаются локально по исходным URL, включая запросы диапазонов для видео. Пользовательские данные, чаты, Socket.IO, LiveKit и API остаются на общем сервере и требуют соединения. Ключи сервера, база пользователей и загруженные вложения в EXE не попадают.

`prepare-assets.cjs` создаёт игнорируемую Git папку `bundled-assets/` и список разрешённых ресурсов. Перед сборкой он собирает публичные файлы, `.next/static` и статические зависимости действующего сайта. JavaScript/CSS/шрифты подменяются только при точном совпадении адреса: после обновления сервера новые файлы с другим хешем загрузятся обычным способом. API, загрузки пользователей и service worker проходят через исходную сессию сайта; cookies и тела POST сохраняются. Сборка завершается ошибкой, если статические зависимости сайта не удалось получить. Локальный режим из исходников предназначен для разработки и этого компьютера.

Сборка без цифровой подписи: Windows может показывать стандартное предупреждение при первом запуске скачанного EXE.

Подготовка ресурсов сначала пишет временную папку; при ошибке скачивания предыдущий комплект остаётся рабочим. Если сервер недоступен, явная сборка с сохранённым фронтендом предыдущего EXE:

```powershell
node desktop/prepare-icons.cjs
node desktop/prepare-native.cjs
node desktop/prepare-assets.cjs --cached-frontend desktop/release/win-unpacked/resources/app.asar
# Запускайте сборщик напрямую, чтобы predist не запрашивал сервер повторно.
Push-Location desktop
npm exec -- electron-builder --win --x64
Pop-Location
```

Кэш должен принадлежать тому же адресу сервера. Переиспользуются только разрешённые статические файлы Next.js по точным URL, а изображения, модели и аудиоресурсы копируются из актуальных исходников.

## Проверка

```powershell
npm run desktop:test
node desktop/tests/built-icons.cjs
# Отдельно: углы, все области изменения размера, локальная загрузка и API.
npm --prefix desktop run test:window-assets
# Отдельно: системный стиль анимации, сворачивание и восстановление окна.
npm --prefix desktop run test:window-animations
# Отдельно: прокрутка, доступный ввод и звонки при изменении размера окна.
npm --prefix desktop run test:viewport
# Перенос участников под «Пригласить», смена группы, статусы и клики.
npm --prefix desktop run test:compact-members
# Отдельно: запуск и остановка реального сервера в изолированной папке данных.
npm --prefix desktop run test:local
# Реальный захват звука в Windows: два внешних приложения и два звука Майко.
npm --prefix desktop run test:screen-audio
```

Тесты проверяют допустимые адреса, сглаживание альфа-канала углов, тёмные боковые отступы, все восемь областей изменения размера, локальное воспроизведение видео, загрузку моделей/WASM, передачу cookies и POST через тестовый сервер, отдельное размещение сайта, изоляцию Node.js, кнопки окна, отмену демонстрации экрана и сохранение сеанса после перезапуска. Аудиотест проверяет через настоящий захват и FFT, что экран содержит внешние приложения, а окно — только выбранное, без голосов и демонстраций, воспроизводимых Майко. Он также проверяет единственный аудиотрек, отказ от передачи звука, клонирование, отмену и повторный запуск. Аудио и изображения экрана в аудиотесте не сохраняются; записываются только измеренные уровни. Smoke-проверка использует Playwright из корня проекта и локальный сайт, не отправляет сообщений и не меняет учётные записи. Скриншоты сохраняются в `desktop/test-output/`.

Документация использованных API: [BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window), [WebContentsView](https://www.electronjs.org/docs/latest/api/web-contents-view), [захват экрана](https://www.electronjs.org/docs/latest/api/session#sessetdisplaymediarequesthandlerhandler-opts), [сборка Windows](https://www.electron.build/nsis.html).
