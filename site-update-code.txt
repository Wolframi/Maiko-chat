# Обновление сайта в браузере и приложении

После `npm run build` и запуска новой сборки сервер отправляет `app:boot` с `buildId` через Socket.IO. Интерфейс сравнивает его с ID загруженного JavaScript. Запасная проверка `/api/health` работает каждые 1,5 секунды; после потери связи проверка временно учащается. Простое перезапускание той же сборки не перезагружает страницы.

## Приложение: демонстрация сохраняется

Статус обновления сайта находится в верхней панели приложения: «Сайт обновляется…», затем «Сайт обновлён». Сообщение об успешном обновлении исчезает через 6 секунд. Повторный сигнал готовности не отменяет таймер. При ошибке загрузки панель показывает «Не удалось обновить сайт» и кнопку повторной попытки. Текст под моделькой внутри приложения убран; сама анимация остаётся.

Новый Electron-клиент проверяет `desktopMediaHost: 1` в `/api/health` и открывает постоянный документ `/desktop-runtime`. В нём живут микрофон, камера, захват экрана, WebRTC/LiveKit, сигнальный сокет и воспроизведение звука. Сам интерфейс находится в iframe того же origin. Его можно перезагрузить, не уничтожая медиадокумент. UI получает живые состояния и MediaStream через `maikoMediaRuntime` версии 1, а его кнопки вызывают методы владельца сессии. Треки не пересоздаются и не передаются через дополнительное WebRTC-соединение.

При обновлении сайта перезагружается только интерфейс: демонстрация и звонок продолжают работать, а новая страница повторно подписывается на существующую сессию. F5 и кнопка обновления оболочки тоже обновляют только UI. Старые подписки удаляются при `pagehide`. Аудиоэлемент остаётся в постоянном документе, поэтому обновление не обрывает воспроизведение и не создаёт его второй экземпляр. Выбор экрана по-прежнему выполняет защищённый Electron-обработчик только для главного медиадокумента.

Микрофон, устройство вывода, шумодав и громкость демонстраций синхронизируются между UI и медиадокументом через изменения общего `localStorage`. Desktop-стили, адаптер списка участников и индикаторы скачивания устанавливаются в каждый новый документ интерфейса. Node.js в страницах и iframe отключён, sandbox и contextIsolation включены. Встраивание разрешено только для `/?_desktop_ui=1` и только внутри того же origin; остальные страницы сохраняют запрет встраивания.

Для этой схемы нужна новая сборка приложения с обновлёнными `main.cjs` и `site-preload.cjs`, а также новая версия сайта. Если сервер ещё не поддерживает `/desktop-runtime`, новый клиент открывает обычный сайт. Обновление EXE с перезапуском всего приложения отличается от обновления веб-интерфейса: закрытие приложения завершает захват. Код владельца медиасессии обновляется при новом запуске приложения, поэтому публичный протокол версии 1 должен оставаться совместимым при обновлении UI.

## Браузер: уведомление во время демонстрации

Если пользователь демонстрирует экран, появляется «Сайт обновился — обновите сайт» с кнопкой «Обновить сайт» и пояснением, что перезагрузка остановит демонстрацию. Автоматической перезагрузки нет. Даже после окончания демонстрации уведомление остаётся, пока пользователь сам не нажмёт кнопку. Кнопка проверяет готовность сервера, резервирует участие в звонке и загружает новую страницу. При недоступности сервера уведомление предлагает повторить попытку.

Сборку выполняйте через `npm run build` в корне или `site/`: `site/scripts/build-site.mjs` задаёт один UUID для всех процессов сборки, `NEXT_PUBLIC_SITE_VERSION` и `.next/BUILD_ID`. Сервер читает этот файл один раз при запуске. Сборка, которая ещё не запущена, не объявляется готовым обновлением.

Во время установленного звонка клиент сохраняет его ID, собеседника, чат, микрофон, наушники, камеру и время начала в `sessionStorage`, затем отправляет `app:prepare-reload`. Авторизованный сервер резервирует участие на 90 секунд и сообщает собеседнику о перезагрузке. После проверки готовности сервера браузер загружает страницу с параметрами `_b` и `_t`, восстанавливает авторизацию и возвращается в тот же звонок. Включается существующая анимация модельки Майко. Микрофон остаётся выключенным до публикации трека, если пользователь выключил его раньше.

Голосовой канал восстанавливается с прежними настройками. Сервер сохраняет звонки и участников каналов в `data/live-media.json` при штатном завершении и восстанавливает их после перезапуска. Участникам даётся 90 секунд на возвращение. Если звонок уже завершён, восстановление не создаёт новый входящий вызов.

В браузере входящий/исходящий вызов, который ещё не установлен, и незавершённое подключение откладывают автоматическую перезагрузку до безопасного момента. Захват экрана браузер разрешает запустить только по действию пользователя, поэтому во время демонстрации требуется решение пользователя через уведомление. Если `sessionStorage` недоступен, во время звонка автоматическая перезагрузка тоже откладывается.

Полная перезагрузка браузерного документа уничтожает WebRTC-соединения. В браузере сохраняется сам звонок и выполняется автоматическое переподключение; возможна короткая пауза звука и видео. В новом приложении медиадокумент не перезагружается. Отдельный сервер LiveKit не следует перезапускать при обновлении сайта.

После первого развёртывания открытые страницы со старым кодом используют прежнее поведение и дождутся окончания звонка. Новый механизм начинает действовать после загрузки этой версии сайта.

Полный механизм обновления и относящиеся к нему фрагменты звонков собраны в `site-update-code.txt`. Чтобы пересобрать этот файл после дальнейших изменений:

```sh
node scripts/export-site-update-code.mjs
```

Проверки: `npm --prefix site test`, `npm --prefix site run build`, `npm --prefix desktop test`, а также `site/e2e/site-reload.spec.ts`, `site/e2e/voice-resume.spec.ts` и `site/e2e/call-media.spec.ts`. `npm --prefix desktop run test:persistent-media` проверяет реальный звонок и захват дисплея, затем смену сборки и ручное обновление UI: ID звонка, исходный MediaStreamTrack и аудиоэлемент должны остаться прежними. Для проверок реального звонка нужны локальный сервер, тестовые аккаунты с `SEED_DEMO=1` и браузер Edge. Тест демонстрации не сохраняет кадры.

import { spawn } from "node:child_process";
import { randomUUID } from "node:crypto";
import { createRequire } from "node:module";

const require = createRequire(import.meta.url);
// One ID for every build worker, the browser bundle and .next/BUILD_ID.
const version = randomUUID();
const child = spawn(process.execPath, [require.resolve("next/dist/bin/next"), "build", ...process.argv.slice(2)], {
  stdio: "inherit",
  windowsHide: true,
  env: { ...process.env, NEXT_PUBLIC_SITE_VERSION: version },
});
child.on("error", (error) => { console.error(error); process.exit(1); });
child.on("exit", (code) => process.exit(code ?? 1));

import {
  canReloadLiveMedia,
  hasLiveMediaSession,
  markPageUnloading,
  persistLiveMediaNow,
} from "@/lib/mediaResume";
import { getDesktopMediaRuntime, isDesktopMediaOwner } from "@/lib/desktopMedia";

const BOOT_KEY = "pulse-boot-id";
const PENDING_KEY = "pulse-boot-pending";
const BOOT_QUERY = "_b";
const RELOAD_NOTICE_KEY = "pulse-site-reloaded";
const MANUAL_KEY = "pulse-site-update-manual";
export type SiteUpdateNotice = { version: string; busy: boolean; error?: string };
let updateNotice: SiteUpdateNotice | null = null;
const noticeListeners = new Set<() => void>();
export const getSiteUpdateNotice = () => updateNotice;
export function subscribeSiteUpdateNotice(listener: () => void) {
  noticeListeners.add(listener);
  return () => { noticeListeners.delete(listener); };
}
function publishNotice(next: SiteUpdateNotice | null) {
  if (JSON.stringify(next) === JSON.stringify(updateNotice)) return;
  updateNotice = next;
  for (const listener of noticeListeners) listener();
}
function manualUpdateRequired() {
  if (updateNotice) return true;
  try { return Boolean(sessionStorage.getItem(MANUAL_KEY)); } catch { return false; }
}
function requireManualUpdate(version: string) {
  writePendingBootId(version);
  try { sessionStorage.setItem(MANUAL_KEY, version); } catch { /* memory notice remains */ }
  publishNotice({ version, busy: false });
}
export function requestPendingSiteReload() {
  const version = pendingBootId();
  if (version) void reloadNow(version, true);
}

export function consumeSiteReloadNotice() {
  try {
    const at = Number(sessionStorage.getItem(RELOAD_NOTICE_KEY));
    sessionStorage.removeItem(RELOAD_NOTICE_KEY);
    return at > 0 && Date.now() - at < 90_000;
  } catch { return false; }
}

/** In-memory copy so a blocked/empty sessionStorage cannot skip reloads forever. */
let memoryBootId = "";
let memoryPendingId = "";
let reloadInProgress = false;
let bootSocket: BootSocket | null = null;
let pollerBound = false;
let pollInFlight: AbortController | null = null;
let burstUntil = 0;
let burstTimer: number | null = null;

function storedBootId() {
  try {
    return sessionStorage.getItem(BOOT_KEY) || "";
  } catch {
    return "";
  }
}

function writeBootId(bootId: string) {
  memoryBootId = bootId;
  try {
    sessionStorage.setItem(BOOT_KEY, bootId);
  } catch {
    /* ignore */
  }
}

function pendingBootId() {
  if (memoryPendingId) return memoryPendingId;
  try {
    return sessionStorage.getItem(PENDING_KEY) || "";
  } catch {
    return "";
  }
}

function writePendingBootId(bootId: string) {
  memoryPendingId = bootId;
  try {
    sessionStorage.setItem(PENDING_KEY, bootId);
  } catch {
    /* ignore */
  }
}

function clearPendingBootId() {
  memoryPendingId = "";
  try {
    sessionStorage.removeItem(PENDING_KEY);
    sessionStorage.removeItem(MANUAL_KEY);
  } catch {
    /* ignore */
  }
  publishNotice(null);
}

function knownBootId() {
  // The loaded bundle is authoritative, including when a stale tab's first
  // health request arrives only AFTER a deployment. Storage alone is not.
  return process.env.NEXT_PUBLIC_SITE_VERSION || memoryBootId || storedBootId();
}

function stripBootQuery() {
  if (typeof window === "undefined") return;
  const url = new URL(window.location.href);
  if (!url.searchParams.has(BOOT_QUERY) && !url.searchParams.has("_t")) return;
  url.searchParams.delete(BOOT_QUERY);
  url.searchParams.delete("_t");
  const search = url.searchParams.toString();
  window.history.replaceState(
    null,
    "",
    `${url.pathname}${search ? `?${search}` : ""}${url.hash}`,
  );
}

async function reloadNow(bootId: string, manual = false) {
  if (reloadInProgress) return;
  persistLiveMediaNow();
  const persistent = Boolean(getDesktopMediaRuntime());
  if (!persistent && !manual && manualUpdateRequired()) {
    requireManualUpdate(bootId);
    return;
  }
  if (!persistent && !manual && !canReloadLiveMedia()) {
    writePendingBootId(bootId);
    // Browsers cannot preserve display capture across document navigation.
    // Once notified, let the user decide even if sharing ends later.
    try {
      const saved = sessionStorage.getItem("pulse-media-resume");
      if (hasLiveMediaSession() && saved && JSON.parse(saved).sharingScreen) requireManualUpdate(bootId);
    } catch { /* no reliable snapshot: keep protecting the current session */ }
    return;
  }
  // Wait for authenticated signaling to rebind after the server restart.
  // The server reserves presence before the old document is destroyed.
  if (!persistent && hasLiveMediaSession() && !bootSocket?.connected) {
    writePendingBootId(bootId);
    return;
  }
  reloadInProgress = true;
  if (manual) publishNotice({ version: bootId, busy: true });
  let navigating = false;
  try {
    if (!persistent && hasLiveMediaSession()) {
      const socket = bootSocket;
      const prepared = await new Promise<boolean>((resolve) => {
        const timer = window.setTimeout(() => resolve(false), 2500);
        socket?.emit?.("app:prepare-reload", { buildId: bootId }, (result) => {
          window.clearTimeout(timer);
          resolve(Boolean(result?.ok));
        });
      });
      if (!prepared) { writePendingBootId(bootId); return; }
    }
    // Verify readiness even for a socket notification: never navigate into
    // a restarting server, an unhealthy deployment or a different version.
    const response = await fetch("/api/health", { cache: "no-store", signal: AbortSignal.timeout(2500) });
    if (!response.ok) { writePendingBootId(bootId); return; }
    const health = await response.json() as BootNotice;
    if (versionOf(health) !== bootId) { writePendingBootId(versionOf(health) || bootId); return; }
    persistLiveMediaNow();
    if (!persistent && !manual && !canReloadLiveMedia()) { writePendingBootId(bootId); return; }
    if (persistent) getDesktopMediaRuntime()?.reportSiteUpdate("loading");
    markPageUnloading();
    writeBootId(bootId);
    clearPendingBootId();
    try { sessionStorage.setItem(RELOAD_NOTICE_KEY, String(Date.now())); } catch { /* optional UI notice */ }
    const url = new URL(window.location.href);
    url.searchParams.set(BOOT_QUERY, bootId);
    url.searchParams.set("_t", String(Date.now()));
    navigating = true;
    window.location.replace(`${url.pathname}${url.search}${url.hash}`);
  } catch {
    writePendingBootId(bootId);
  } finally {
    if (!navigating) {
      reloadInProgress = false;
      if (manual) publishNotice({ version: pendingBootId() || bootId, busy: false, error: "Сервер пока недоступен. Попробуйте ещё раз." });
    }
  }
}

/** Reload a ready deployment and restore the existing media session. */
export function applyBootId(bootId: string) {
  if (!bootId || typeof window === "undefined") return;
  const prev = knownBootId();
  if (!prev) {
    writeBootId(bootId);
    return;
  }
  if (prev === bootId) {
    memoryBootId = bootId;
    clearPendingBootId();
    return;
  }
  void reloadNow(bootId);
}

/** Retry once ringing, screen sharing or a pending media join has ended. */
export function flushPendingBootReload() {
  if (typeof window === "undefined") return;
  const pending = pendingBootId();
  if (!pending) return;
  if (pending === knownBootId()) {
    clearPendingBootId();
    return;
  }
  void reloadNow(pending);
}

type BootNotice = { bootId?: string; buildId?: string };
function versionOf(notice: BootNotice) {
  const value = notice.buildId || notice.bootId || "";
  return typeof value === "string" && /^[a-zA-Z0-9_-]{1,128}$/.test(value) ? value : "";
}

async function pollHealth() {
  if (pollInFlight) return;
  // Hidden tabs don't need the reload-deploy ping every 1.5s.
  if (typeof document !== "undefined" && document.hidden) return;
  const ac = new AbortController();
  pollInFlight = ac;
  const timeout = window.setTimeout(() => ac.abort(), 2500);
  try {
    const res = await fetch("/api/health", {
      cache: "no-store",
      headers: { "Cache-Control": "no-cache", Pragma: "no-cache" },
      signal: ac.signal,
    });
    if (!res.ok) return;
    const data = (await res.json()) as BootNotice;
    const version = versionOf(data);
    if (version) applyBootId(version);
    flushPendingBootReload();
  } catch {
    /* server is bouncing — burst poll will retry */
  } finally {
    window.clearTimeout(timeout);
    if (pollInFlight === ac) pollInFlight = null;
  }
}

function startBurstPoll() {
  burstUntil = Date.now() + 45_000;
  if (burstTimer != null) return;
  const tick = () => {
    void pollHealth();
    if (Date.now() < burstUntil) {
      burstTimer = window.setTimeout(tick, 400);
    } else {
      burstTimer = null;
    }
  };
  tick();
}

function onVisible() {
  if (typeof document !== "undefined" && document.hidden) return;
  startBurstPoll();
}

function ensurePoller() {
  if (pollerBound || typeof window === "undefined") return;
  pollerBound = true;
  stripBootQuery();
  document.addEventListener("visibilitychange", onVisible);
  window.addEventListener("online", onVisible);
  window.addEventListener("focus", onVisible);
  window.addEventListener("pageshow", onVisible);
  void pollHealth();
  window.setInterval(() => {
    void pollHealth();
  }, 1_500);
}

type BootSocket = {
  connected?: boolean;
  emit?: (event: "app:prepare-reload", payload: { buildId: string }, ack: (result?: { ok?: boolean }) => void) => void;
  on: (
    event: "app:boot" | "connect" | "disconnect",
    fn: (payload?: BootNotice) => void,
  ) => void;
  off: (
    event: "app:boot" | "connect" | "disconnect",
    fn: (payload?: BootNotice) => void,
  ) => void;
};

export function watchAppBoot(socket: BootSocket | null) {
  // The media owner survives deployments; only its child UI checks versions.
  if (isDesktopMediaOwner()) return () => {};
  ensurePoller();
  if (socket) bootSocket = socket;

  const onBoot = (payload: BootNotice | undefined) => {
    const version = payload && versionOf(payload);
    if (version) applyBootId(version);
  };
  const onConnect = () => {
    void pollHealth();
  };
  const onDisconnect = () => {
    startBurstPoll();
  };

  socket?.on("app:boot", onBoot);
  socket?.on("connect", onConnect);
  socket?.on("disconnect", onDisconnect);

  return () => {
    if (socket && bootSocket === socket) bootSocket = null;
    socket?.off("app:boot", onBoot);
    socket?.off("connect", onConnect);
    socket?.off("disconnect", onDisconnect);
  };
}

export type MediaResume =
  | {

      mode: "audio" | "video";
      muted: boolean;
      cameraOff: boolean;

      callId?: string;
      connectedAt?: number;
      sharingScreen?: boolean;
      at: number;
    }
  | {
      kind: "voice";
      channelId: string;
      groupId: string;
      title: string;
      muted: boolean;
      deafened: boolean;
      cameraOff: boolean;
      sharingScreen?: boolean;
      at: number;
    };

type CallResumeInput = Omit<Extract<MediaResume, { kind: "call" }>, "at">;
type VoiceResumeInput = Omit<Extract<MediaResume, { kind: "voice" }>, "at">;

let pageUnloading = false;
const liveMedia = { call: false, voice: false };
const reloadBlocked = { call: false, voice: false };

const persistHooks = new Set<() => void>();

if (typeof window !== "undefined") {
  window.addEventListener("pagehide", () => {
    pageUnloading = true;
  });
}

/** Keep resume snapshot through a deploy reload. */
export function markPageUnloading() {
  pageUnloading = true;
}

export function registerMediaResumePersist(fn: () => void) {
  persistHooks.add(fn);
  return () => {
    persistHooks.delete(fn);
  };
}

export function persistLiveMediaNow() {
  for (const fn of persistHooks) {
    try {
      fn();
    } catch {
      /* ignore */
    }
  }
}

export function isPageUnloading() {
  return pageUnloading;
}

/** True while a 1:1 call or group voice session is open in this tab. */
export function setLiveMediaSession(kind: "call" | "voice", on: boolean, reloadable = true) {
  liveMedia[kind] = on;
  reloadBlocked[kind] = on && !reloadable;
}

export function hasLiveMediaSession() {
  return liveMedia.call || liveMedia.voice;
}

/** Screen capture requires a fresh user gesture; ringing must not auto-answer. */
export function canReloadLiveMedia() {
  if (!hasLiveMediaSession()) return true;
  if (reloadBlocked.call || reloadBlocked.voice) return false;
  const resume = peekMediaResume();
  if (!resume || resume.sharingScreen) return false;
  if (liveMedia.call) return resume.kind === "call" && Boolean(resume.callId && resume.connectedAt);
  return resume.kind === "voice";
}

export function saveMediaResume(session: CallResumeInput | VoiceResumeInput) {
  if (typeof window === "undefined") return;
  try {
    const payload = { ...session, at: Date.now() } as MediaResume;
    sessionStorage.setItem(KEY, JSON.stringify(payload));
  } catch {
    /* ignore */
  }
}

export function peekMediaResume(): MediaResume | null {
  if (typeof window === "undefined") return null;
  try {
    const raw = sessionStorage.getItem(KEY);
    if (!raw) return null;
    const parsed = JSON.parse(raw) as MediaResume;
    if (!parsed || (parsed.kind !== "call" && parsed.kind !== "voice")) {
      sessionStorage.removeItem(KEY);
      return null;
    }
    if (!parsed.at || Date.now() - parsed.at > MAX_AGE_MS) {
      sessionStorage.removeItem(KEY);
      return null;
    }
    return parsed;
  } catch {
    return null;
  }
}

  chatId: string;
  panel?: string;
};

  }

  } catch {

  }
}

/** Same-origin child only. The permanent owner never proxies its own hooks. */
export function getDesktopMediaRuntime(): DesktopMediaRuntime | null {
  if (typeof window === "undefined" || window.parent === window) return null;
  try {
    if (window.parent.location.origin !== window.location.origin) return null;
    const runtime = window.parent.maikoMediaRuntime;
    return runtime?.version === 1 ? runtime : null;
  } catch { return null; }

function subscribe(listener: () => void) {
  const stop = getDesktopMediaRuntime()?.subscribe(listener) ?? (() => {});
  // Navigation does not unmount a React tree. Remove the old frame's closures
  // from the permanent owner's subscriptions before destroying the document.
  window.addEventListener("pagehide", stop, { once: true });
  return () => { stop(); window.removeEventListener("pagehide", stop); };
}

export function useDesktopMedia(session: Partial<DesktopMediaSession>) {
  const snapshot = useSyncExternalStore(subscribe, getSnapshot, serverSnapshot);
  useEffect(() => {
    if (!session.token || !session.selfId) return;
    getDesktopMediaRuntime()?.configureSession({ token: session.token, selfId: session.selfId, selfName: session.selfName });
  }, [session.token, session.selfId, session.selfName]);
  return snapshot;
}

import { useCallback, useEffect, useRef, useState } from "react";

export function DesktopMediaHost() {
  const [enabled, setEnabled] = useState(false);
  const [session, setSession] = useState<DesktopMediaSession | null>(null);
  const [socket, setSocket] = useState<Socket | null>(null);
  const [revision, setRevision] = useState(0);
  const listeners = useRef(new Set<() => void>());
  const snapshot = useRef<DesktopMediaSnapshot | null>(null);
  const reportSiteUpdate = useCallback((phase: "loading" | "ready" | "error") => {
    void window.maikoMediaShell?.siteUpdate(phase).catch(() => {});
  }, []);
  const refresh = useCallback(() => {
    reportSiteUpdate("loading");
    setRevision(value => value + 1);
  }, [reportSiteUpdate]);
  const [runtime] = useState<DesktopMediaRuntime>(() => ({
    version: 1, getSnapshot: () => snapshot.current,
    subscribe(listener) { listeners.current.add(listener); return () => { listeners.current.delete(listener); }; },
    configureSession(next) { setSession(previous => previous?.token === next.token && previous.selfId === next.selfId && previous.selfName === next.selfName ? previous : next); },
    refresh,
    reportSiteUpdate,
  }));
  const transport = useRef<Socket | null>(null);
  const call = useBrowserCall({ socket, selfId: session?.selfId, token: session?.token,
    onLog: useCallback((chatId: string, text: string) => transport.current?.emit("call:log", { chatId, text }), []),
  });
  const voice = useBrowserVoiceChannel({ socket, selfId: session?.selfId, selfName: session?.selfName,
    token: session?.token, callBusy: Boolean(call.active || call.incoming) });

  useEffect(() => {
    if (!isDesktopMediaOwner()) return;
    setEnabled(true);
    window.maikoMediaRuntime = runtime;
    const stopRefresh = window.maikoMediaShell!.onRefresh(refresh);
    return () => { stopRefresh(); delete window.maikoMediaRuntime; };
  }, [runtime, refresh]);

  useEffect(() => {
    snapshot.current = { call, voice };
    for (const listener of listeners.current) listener();
  }, [call, voice]);

  useEffect(() => {
    if (!enabled) return;
    const client = io({ path: "/api/socket", autoConnect: false, transports: ["polling", "websocket"],
      rememberUpgrade: true, reconnectionDelay: 700, reconnectionDelayMax: 8000 });
    transport.current = client;
    const restore = () => {
      const token = localStorage.getItem("pulse-chat-token");
      if (!token) return;
      client.emit("auth:restore", { token }, (result: { ok?: boolean; account?: { userId: string; displayName?: string; username: string } }) => {
        if (localStorage.getItem("pulse-chat-token") !== token) return;
        if (!result.ok || !result.account) { setSession(null); setSocket(null); return; }
        setSession(previous => previous?.token === token ? previous : { token, selfId: result.account!.userId,
          selfName: result.account!.displayName || result.account!.username });
        setSocket(client);
      });
    };
    client.on("connect", restore);
    client.on("disconnect", reason => { if (reason === "io server disconnect") client.connect(); });
    const changed = (event: StorageEvent) => {
      if (event.key !== "pulse-chat-token") return;
      if (!event.newValue) { setSession(null); setSocket(null); }
      else restore();
    };
    window.addEventListener("storage", changed);
    client.connect();
    return () => { window.removeEventListener("storage", changed); client.disconnect(); transport.current = null; };
  }, [enabled]);

  useEffect(() => {
    const client = transport.current;
    if (!session?.token || !client?.connected) return;
    client.emit("auth:restore", { token: session.token }, (result: { ok?: boolean }) => {
      if (localStorage.getItem("pulse-chat-token") !== session.token) return;
      if (result.ok) setSocket(client);
    });
  }, [session?.token]);

  useEffect(() => {
    configureCallAudioCapture(Boolean(call.active || voice.active));
    return () => configureCallAudioCapture(false);
  }, [call.active, voice.active]);

  if (!enabled) return <p>Эта страница используется приложением Майко.</p>;
  return <>
    <audio ref={call.remoteAudioRef} autoPlay playsInline hidden />
    <iframe key={revision} data-maiko-desktop-ui title="Майко" src="/?_desktop_ui=1"
      allow="camera; microphone; display-capture; autoplay; clipboard-read; clipboard-write"
      style={{ position: "fixed", inset: 0, width: "100%", height: "100%", border: 0 }} />
  </>;
}

const { contextBridge, ipcRenderer } = require('electron');

// No renderer controls or IPC primitives are exposed. This signal only lets
// the trusted site's permanent media document refresh its own child UI.
contextBridge.exposeInMainWorld('maikoMediaShell', Object.freeze({
  version: 1,
  siteUpdate: (phase) => ipcRenderer.invoke('desktop:site-update-state', phase),
  onRefresh: (callback) => {
    const handler = () => callback();
    ipcRenderer.on('desktop:refresh-interface', handler);
    return () => ipcRenderer.removeListener('desktop:refresh-interface', handler);
  },
}));

// Only our isolated DOM helper can see this bridge. No filesystem paths or
// folder-opening commands are exposed to the remotely loaded messenger.
contextBridge.exposeInIsolatedWorld(1001, 'maikoDownloadProgress', Object.freeze({
  state: () => ipcRenderer.invoke('desktop:site-downloads-state'),
  cancel: (id) => ipcRenderer.invoke('desktop:site-downloads-cancel', id),
  onState: (callback) => {
    const handler = (_event, state) => callback(state);
    ipcRenderer.on('desktop:site-downloads-changed', handler);
    return () => ipcRenderer.removeListener('desktop:site-downloads-changed', handler);
  },
}));

// Read-only capture metadata. The site still has no shell, filesystem or
// window-control bridge. The main process accepts this only from its site.
contextBridge.exposeInMainWorld('maikoScreenAudio', Object.freeze({
  takePolicy: () => ipcRenderer.invoke('desktop:capture-audio-policy'),
}));

contextBridge.executeInMainWorld({ func: () => {
  const devices = navigator.mediaDevices;
  if (!devices?.getDisplayMedia) return;
  const capture = devices.getDisplayMedia.bind(devices);
  let capturing = false;
  function describeIsolatedTrack(track) {
    const settings = track.getSettings.bind(track);
    const clone = track.clone.bind(track);
    // Chromium on Windows 10 reports restrictOwnAudio=false even for its
    // native process-isolated devices. Report the policy actually applied by
    // the desktop handler, so the deployed site's safety check accepts it.
    // This changes metadata only; filtering happens natively before encoding.
    Object.defineProperty(track, 'getSettings', {
      value: () => ({ ...settings(), restrictOwnAudio: true }),
    });
    Object.defineProperty(track, 'clone', {
      value: () => { const cloned = clone(); describeIsolatedTrack(cloned); return cloned; },
    });
  }
  Object.defineProperty(devices, 'getDisplayMedia', {
    value: async (options) => {
      if (capturing) throw new DOMException('Демонстрация уже выбирается', 'InvalidStateError');
      capturing = true;
      let stream;
      try {
        stream = await capture(options);
        const policy = await window.maikoScreenAudio.takePolicy();
        if (policy?.isolated === true) {
          for (const track of stream.getAudioTracks()) describeIsolatedTrack(track);
        } else {
          // A missing policy must never produce an unfiltered call loopback.
          for (const track of stream.getAudioTracks()) { track.stop(); stream.removeTrack(track); }
        }
        return stream;
      } catch (error) {
        stream?.getTracks().forEach((track) => track.stop());
        throw error;
      } finally { capturing = false; }
    },
  });
} });

  element('site-update-dock').hidden = sitePhase === 'idle';

    element('update-status').textContent = update.message;

    element('update-dock').title = update.message;

        const ackIndex = packet.length - 1;
        const acknowledge = packet[ackIndex];
        if (typeof acknowledge === "function") {
          packet[ackIndex] = (result: { ok?: boolean; error?: string }) => {
            if (!result?.ok) { acknowledge(result); return; }

            );
          };
        }

      });

function afterAuth(io: Server, socket: Socket, account: AuthAccount) {
  cancelCallDisconnectTimer(account.userId);
  const voiceGrace = voiceDisconnectTimers.get(account.userId);
  if (voiceGrace) {
    clearTimeout(voiceGrace);
    voiceDisconnectTimers.delete(account.userId);
  }
  const existing = usersBySocket.get(socket.id);
  usersBySocket.set(socket.id, {
    userId: account.userId,
    name: labelOf(account),
    room: existing?.room ?? null,
  });
  emitChats(socket, account.userId);
  broadcastPeople(io);

  // Re-deliver ringing call after phone woke / tab reconnected.
  const ringing = ringingCallForUser(account.userId);
  if (ringing) {
    const caller = getUserById(ringing.callerId);
    socket.emit("call:incoming", {
      callId: ringing.callId,
      fromUserId: ringing.callerId,
      fromName: caller?.displayName || caller?.username || "Майко",
      mode: ringing.mode,
      chatId: ringing.chatId,
    });
  }

  const liveCallId = callByUser.get(account.userId);
  const liveCall = liveCallId ? callsById.get(liveCallId) : null;
  if (liveCall && liveCall.status === "active") {
    const peerId =
      liveCall.callerId === account.userId ? liveCall.calleeId : liveCall.callerId;
    const peer = getUserById(peerId);
    if (callByUser.get(peerId) !== liveCall.callId) {
      // Peer already left this call — it's a ghost. Kill it instead of
      // resuming a call that only exists in stale state.
      clearCall(liveCall.callId);
    } else {
      const peerPresent = userIsConnected(peerId);
      socket.emit("call:resume", {
        callId: liveCall.callId,
        peerId,
        peerName: peer?.displayName || peer?.username || "Майко",
        mode: liveCall.mode,
        chatId: liveCall.chatId,
        role: liveCall.callerId === account.userId ? "caller" : "callee",
        peerPresent,
      });
      if (peerPresent && socketsForUser(account.userId).length <= 1) {
        emitToUser(io, peerId, "call:resume", {
          callId: liveCall.callId,
          peerId: account.userId,
          peerName: labelOf(account),
          mode: liveCall.mode,
          chatId: liveCall.chatId,
          role: liveCall.callerId === peerId ? "caller" : "callee",
          peerPresent: true,
        });
      }
    }
  }
}

  const startCall = useCallback(
    async (
      peerId: string,
      peerName: string,
      mode: CallMode,
      chatId: string,
      opts?: { reconnect?: boolean },
    ) => {
      if (!socket || !selfId) return;
      if (busyRef.current) {
        if (!opts?.reconnect) setStatus("Уже есть активный звонок");
        return;
      }

      busyRef.current = true;
      const saved = opts?.reconnect ? peekMediaResume() : null;
      if (opts?.reconnect) prepareResumeControls(peerId, chatId);
      outboundRef.current = true;
      peerLeftRef.current = false;
      setMinimized(false);
      setActive({
        peerId,
        peerName,
        mode,
        chatId,
        outbound: true,
        callId: "",
      });
      if (!opts?.reconnect) setStatus("Звоним…");

      try {
        await ensureIceServers();
        await getMedia(mode);
      } catch (error) {
        const message =
          error instanceof Error && /микрофон|microphone|NotAllowed|Permission/i.test(error.message)
            ? "Нет доступа к микрофону"
            : "Не удалось начать звонок";
        setStatus(message);
        scheduleCleanup(1400);
        return;
      }

      if (!opts?.reconnect) {
        startRingTimer(() => {
          setStatus("Нет ответа");
          clearMediaResume();
          if (peerRef.current) {
            emitSignal(peerId, "end");
            onLog?.(chatId, "Звонок без ответа");
          }
          scheduleCleanup(1400);
        });
      }

      const inviteOnce = () =>
        new Promise<{
          ok: boolean;
          callId?: string;
          resume?: boolean;
          role?: "caller" | "callee";
          peerPresent?: boolean;
          error?: string;
        }>((resolve) => {
          socket.emit(
            "call:invite",
            { toUserId: peerId, mode, chatId, reconnect: Boolean(opts?.reconnect),
              callId: saved?.kind === "call" ? saved.callId : undefined },
            (result: {
              ok: boolean;
              callId?: string;
              resume?: boolean;
              role?: "caller" | "callee";
              peerPresent?: boolean;
              error?: string;
            }) => resolve(result || { ok: false }),
          );
        });

      let result = await inviteOnce();
      if (opts?.reconnect) {
        for (let attempt = 0; attempt < 16 && !result.ok; attempt += 1) {
          if (result.error && result.error !== "Собеседник не в сети") break;
          await new Promise((resolve) => window.setTimeout(resolve, 900));
          if (!busyRef.current) return;
          result = await inviteOnce();
        }
      }

      if (!result?.ok || !result.callId) {
        setStatus(result?.error || "Не удалось позвонить");
        if (!opts?.reconnect) clearMediaResume();
        scheduleCleanup(1400);
        return;
      }
      callIdRef.current = result.callId;
      peerRef.current = { peerId, chatId, mode, callId: result.callId };
      setActive((prev) =>
        prev ? { ...prev, callId: result.callId!, outbound: result.role !== "callee" } : prev,
      );

      if (result.resume) {
        if (ringTimerRef.current) {
          clearTimeout(ringTimerRef.current);
          ringTimerRef.current = null;
        }
        setStatus("Переподключение…");
        if (result.peerPresent === false) return;
        try {
          if (result.role === "callee") {
            acceptReadyRef.current = true;
            emitSignal(peerId, "accept");
          } else {
            await createOffer(peerId, mode, { resetPc: true });
          }
        } catch {
          setStatus("Не удалось переподключить звонок");
        }
      }
    },

    await remote.getByRole('button', { name: 'Люди', exact: true }).click();
    await remote.getByRole('button', { name: /Artem.*@artem/ }).click();
    await ui.getByRole('button', { name: 'Звонок', exact: true }).click();
    await remote.getByRole('button', { name: 'Ответить', exact: true }).click();
    await site.waitForFunction(() => window.maikoMediaRuntime?.getSnapshot()?.call.status === 'На линии', null, { timeout: 30_000 });
    console.log('Local call connected.');
    await site.evaluate(() => {
      const original = navigator.mediaDevices.getDisplayMedia.bind(navigator.mediaDevices);
      navigator.mediaDevices.getDisplayMedia = async options => {
        window.captureDebug = { active: navigator.userActivation.isActive, focus: document.hasFocus() };
        try { return await original(options); }
        catch (error) { window.captureDebug.error = error.name + ': ' + error.message; throw error; }
      };
    });
    const pickerReady = app.waitForEvent('window', { predicate: page => page !== site && page !== shell, timeout: 20_000 });
    await ui.getByRole('button', { name: 'Демонстрация экрана', exact: true }).click();
    const picker = await pickerReady.catch(async error => {
      console.error(await site.evaluate(() => ({ capture: window.captureDebug, status: window.maikoMediaRuntime.getSnapshot().call.status })));
      throw error;
    });
    await picker.waitForFunction(() => window.maikoDesktop?.captureSources);
    const sources = await picker.evaluate(() => window.maikoDesktop.captureSources());
    const source = sources.sources.find(entry => entry.id.startsWith('screen:'));
    assert.ok(source, 'A display is available');
    await picker.evaluate(id => window.maikoDesktop.captureSelect({ id, audio: false }), source.id).catch(error => { if (!picker.isClosed()) throw error; });
    await site.waitForFunction(() => window.maikoMediaRuntime?.getSnapshot()?.call.sharingScreen, null, { timeout: 20_000 });
    console.log('Original display capture is live.');
    const before = await site.evaluate(() => {
      const call = window.maikoMediaRuntime.getSnapshot().call;
      window.screenBeforeUpdate = call.localStream.getVideoTracks().find(track => track.contentHint === 'detail');
      window.audioBeforeUpdate = document.querySelector('audio');
      return { callId: call.active.callId, track: window.screenBeforeUpdate.id };
    });
    await remote.waitForFunction(() => [...document.querySelectorAll('video')].some(video => video.videoWidth > 0), null, { timeout: 20_000 });

    let ownerNavigations = 0;
    await site.evaluate(() => {
      window.uiDocumentLoads = 0;
      document.querySelector('iframe[data-maiko-desktop-ui]').addEventListener('load', () => { window.uiDocumentLoads++; });
    });
    site.on('framenavigated', frame => {
      if (frame === site.mainFrame()) ownerNavigations++;
    });
    simulateDeployment = true;
    await shell.getByText('Сайт обновляется…', { exact: true }).waitFor({ timeout: 15_000 });
    await site.waitForFunction(() => sessionStorage.getItem('pulse-boot-id') === 'screen-update-test', null, { timeout: 15_000 });
    await site.waitForFunction(() => window.uiDocumentLoads === 1, null, { timeout: 20_000 });
    await ui.locator('.workspace').waitFor({ timeout: 30_000 });
    await shell.getByText('Сайт обновлён', { exact: true }).waitFor({ timeout: 10_000 });
    assert.equal(await ui.locator('.boot__update').count(), 0, 'Update text belongs to the top desktop dock');
    const after = await site.evaluate(() => {
      const call = window.maikoMediaRuntime.getSnapshot().call;
      const screen = call.localStream.getVideoTracks().find(track => track.contentHint === 'detail');
      return { callId: call.active.callId, track: screen.id, sameTrack: screen === window.screenBeforeUpdate,
        live: screen.readyState, sharing: call.sharingScreen, sameAudioElement: document.querySelector('audio') === window.audioBeforeUpdate };
    });
    assert.equal(after.callId, before.callId);
    assert.equal(after.track, before.track);
    assert.equal(after.sameTrack, true);
    assert.equal(after.live, 'live');
    assert.equal(after.sharing, true);
    assert.equal(after.sameAudioElement, true);
    assert.equal(ownerNavigations, 0);
    assert.equal(await site.evaluate(() => window.uiDocumentLoads), 1);
    assert.equal(await ui.getByText('Сайт обновился — обновите сайт').count(), 0);
    assert.ok(await ui.getByRole('button', { name: 'Остановить демонстрацию', exact: true }).count());
    // Repeated ready reports must not cancel the countdown or keep the dock visible.
    await site.evaluate(() => window.maikoMediaRuntime.reportSiteUpdate('ready'));
    await shell.locator('#site-update-dock').waitFor({ state: 'hidden', timeout: 10_000 });
    const uiLoadedAt = await site.evaluate(() => document.querySelector('iframe[data-maiko-desktop-ui]').contentWindow.performance.timeOrigin);
    await shell.evaluate(() => window.maikoDesktop.control('reload'));
    await site.waitForFunction(previous => {
      const frame = document.querySelector('iframe[data-maiko-desktop-ui]');
      return frame?.contentWindow.performance.timeOrigin !== previous && frame?.contentDocument.querySelector('.workspace');
    }, uiLoadedAt, { timeout: 30_000 });
    await ui.locator('.workspace').waitFor({ timeout: 30_000 });
    assert.equal(await site.evaluate(() => window.screenBeforeUpdate.readyState), 'live');
    assert.equal(ownerNavigations, 0);
    await ui.getByRole('button', { name: /^Завершить(?: звонок)?$/ }).click();
    console.log('PASS: server update and manual UI refresh preserve the original screen track, call ID and audio owner; no recapture or call leave.');
  } finally {
    await site?.evaluate(() => window.maikoMediaRuntime?.getSnapshot()?.call.endCall()).catch(() => {});
    await app?.close().catch(() => {}); await browser?.close().catch(() => {});
    for (const socket of connections) socket.destroy();
    await new Promise(resolve => proxy.close(resolve));
  }
}
main().catch(error => { console.error(error); process.exitCode = 1; });
